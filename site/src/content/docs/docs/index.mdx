fiXmArge Script (fxma) は、架空言語「フィクスマージ語」の単語をキーワードにしたスクリプト言語です。このドキュメントは、言語を使う人向けのガイドです。言語の決まりは、左の「言語」と「標準パッケージ」から読めます。
