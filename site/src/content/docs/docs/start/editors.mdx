どのエディタでも、シンタックスハイライトとインデントは単体で動きます。診断・補完・ホバー・定義へ移動・フォーマットは、言語サーバー `fixmarge trench` が行うので、先に [`fixmarge` をインストール](/docs/start/install/)しておきます。

エディタは `fixmarge` を `PATH` から探し、見つからなければ次のインストール先も探します。`fixmarge` をインストールする前から開いていたエディタは古い `PATH` のままなので、そのためです。

| インストール方法 | 場所 |
| --- | --- |
| Windows のセットアップ | `%LOCALAPPDATA%\Programs\fixmarge` (全員向けなら `%ProgramFiles%\fixmarge`) |
| install.sh | `~/.fixmarge/bin` (`FIXMARGE_INSTALL` があればその下の `bin`) |
| `go install` | `GOBIN` か `~/go/bin` (`GOPATH` があればその下の `bin`) |

どこにもなければ、言語サーバーにはつながず `Nii eXi' fixmarge` と表示します。

## VS Code

拡張機能 `otoneko1102.fixmarge` をインストールします。VSCodium や Cursor では Open VSX から同じ拡張機能をインストールできます。

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| `fixmarge.path` | `fixmarge` | 言語サーバーとして動かす `fixmarge` の名前か場所。名前だけなら `PATH` とインストール先から探す |

## Vim と Neovim

リポジトリがそのままプラグインです。どのプラグインマネージャーでも、リポジトリの名前を書くだけでインストールできます。Vim 8.2 以降と Neovim 0.10 以降に対応しています。

| プラグインマネージャー | エディタ | 書き方 |
| --- | --- | --- |
| [lazy.nvim](https://github.com/folke/lazy.nvim) | Neovim | `{ 'otnc/fiXmArgeScript' }` |
| vim.pack | Neovim 0.12 以降 | `vim.pack.add({ 'https://github.com/otnc/fiXmArgeScript' })` |
| [mini.deps](https://github.com/echasnovski/mini.deps) | Neovim | `MiniDeps.add('otnc/fiXmArgeScript')` |
| [packer.nvim](https://github.com/wbthomason/packer.nvim) | Neovim | `use('otnc/fiXmArgeScript')` |
| [paq-nvim](https://github.com/savq/paq-nvim) | Neovim | `'otnc/fiXmArgeScript',` |
| [vim-plug](https://github.com/junegunn/vim-plug) | Vim・Neovim | `Plug 'otnc/fiXmArgeScript'` |
| [dein.vim](https://github.com/Shougo/dein.vim) | Vim・Neovim | `call dein#add('otnc/fiXmArgeScript')` |
| [vim-jetpack](https://github.com/tani/vim-jetpack) | Vim・Neovim | `Jetpack 'otnc/fiXmArgeScript'` |
| パッケージ (`:help packages`) | Vim・Neovim | Vim は `~/.vim/pack/fixmarge/start/`、Neovim は `~/.local/share/nvim/site/pack/fixmarge/start/` に `git clone` する |

バージョンは `fixmarge` と同じ Git のタグ (`v0.1.0` など) で選べます。lazy.nvim と vim.pack は `version`、vim-plug は `tag` に書きます。

このプラグインは次のことをします。

- ファイルタイプ `fixmarge` (`.fxma`) と `fixmargec` (`.fxmac`) を付ける。`fixmarge.mod` には `fixmargemod`、`fixmarge.sum` には `fixmargesum` を付ける
- シンタックスハイライト
- インデント。`.fxma` は `fixmarge beaukshi` と同じく空白2つで、`finend` などを打ち終えるとインデントし直す。`.fxmac` はインデントしない
- コメント (`#`) の設定と、`gf` で `werer` の読み込み先を開くための `suffixesadd`
- 言語サーバーに自動でつなぐ

### 言語サーバー

`fixmarge` のファイルを開くと、言語サーバーに自動でつなぎます。

- **Neovim 0.11 以降**: `vim.lsp.config('fixmarge', ...)` で設定を書き、`vim.lsp.enable('fixmarge')` でつなぎます。設定を変えるときは、このプラグインが読み込まれる前に `vim.lsp.config('fixmarge', { ... })` で書きます。書いた所はそのまま使い、書いていない所だけをプラグインが埋めます。
- **Neovim 0.10**: ファイルを開いたときに `vim.lsp.start()` でつなぎます。
- **Vim**: 言語サーバーをつなぐ機能が組み込まれていないので、yegappan/lsp・vim-lsp・coc.nvim・ALE の順に探し、最初に見つかった1つに登録します。2つに登録すると、同じ診断が二重に出るためです。どれも入っていなければ、シンタックスハイライトとインデントだけが使えます。

フォーマットは、Neovim なら `vim.lsp.buf.format()`、Vim なら使っている LSP プラグインのコマンドで行います。

### 設定

設定は、このプラグインが読み込まれる前に書きます (lazy.nvim なら `init`)。

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `g:fixmarge_lsp` | `1` | `0` なら言語サーバーに自動でつながない。自分の設定でつなぐときに使う |
| `g:fixmarge_path` | `'fixmarge'` | 言語サーバーとして動かす `fixmarge` の名前か場所。名前だけなら `PATH` とインストール先から探し、パスを書けばそのファイルだけを使う (`~` も書ける) |
| `g:fixmarge_recommended_style` | `1` | `1` なら `expandtab` を付け、`shiftwidth` と `softtabstop` を `2` にする (`fixmarge beaukshi` と同じ)。自分の設定を使うときは `0` |

```vim
let g:fixmarge_lsp = 0
let g:fixmarge_path = '~/bin/fixmarge'
let g:fixmarge_recommended_style = 0
```
