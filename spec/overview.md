# 概要

fiXmArge Script (略称 fxma) は、ゲーム『魔法少女ノ魔女裁判』 (まのさば) に出てくる架空言語「フィクスマージ語」の単語をキーワードにした、小さなインタプリタ言語です。非公式のファンメイド作品です。FizzBuzz や簡単な推理パズルが書ける程度の規模を目指しています。

## 名前

架空言語の名前「fiXmArge」に「Script」を付けた名前です。「fiXmArge」だけだと架空言語そのものと区別がつかないので、この言語を呼ぶときは「Script」を省きません。略称の fxma は、**f**i**XmA**rge の f・X・m・A を取ったものです。

| 用途 | 名前 |
| --- | --- |
| コマンド、npm パッケージ、VS Code 拡張 | `fixmarge` |
| ソースファイル (下書き) | `.fxma` |
| ビルドしたファイル (清書) | `.fxmac` |
| パッケージの設定とハッシュ | `fixmarge.mod`、`fixmarge.sum` |

下書きと清書の違いは [表記](notation.md) で説明します。

公式の作品と間違えられないよう、名前の近くには必ず「非公式のファンメイド作品」と書きます。

## 設計方針

- **キーワードは辞書にある語だけを使う**: キーワードは、設定資料集の翻訳表を写したとされるファン辞書から選びます。辞書にない語は作りません。
- **ソースには記号を書かない**: `Iz'u` は `izu` と書きます。ビルドすると正式な綴りに直ります。
- **ゲームの仕組みを言語の機能に当てはめる**: 選択肢とバッドエンドをバックトラックに、証拠品を定数に、魔法を副作用の宣言に、魔女裁判をテストに対応させます。詳しくは [言語の特徴](features.md) にあります。
- **フィクスマージ語を知らなくても読める**: 各機能に、同じことを JavaScript と Python で書いた例を付けます。

語彙の出典と信頼度は [出典](sources.md) にまとめています。
