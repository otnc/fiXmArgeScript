# 二次創作ガイドラインと法的な対応

この言語は、公式の配信・二次創作ガイドライン (2026年10月21日更新版) の「9. 二次創作ゲーム・アプリ」に当たるものとして扱います。公開のたびに、最新のガイドラインを確認し直します。

## ガイドラインの条件と対応

| 条件 | 項目 | この言語での対応 |
| --- | --- | --- |
| 完全無料で提供する | 9 | CLI、WebAssembly 版、プレイグラウンドをすべて無料にする |
| 広告、寄付、投げ銭などで収益を得ない | 9 | GitHub Sponsors などの寄付リンクと、サイトの広告を置かない |
| 公式のイラスト、ロゴ、楽曲、シナリオなどを直接組み込まない | 7・9 | ロゴや画像は使わない。歌詞の文は入れず、キーワードには単語だけを使う |
| 素材は自作か、権利処理済みのものだけ | 9 | アイコンなどは自作する。ライセンスのない辞書 CSV は同梱しない |
| 「非公式のファンメイド作品」と配信ページと作品内に明記する | 9 | 配信ページ: リポジトリの README、Releases、npm、サイト。作品内: `fixmarge gun`、インストーラの同意画面、同梱の README |
| 公式の続編や公認作品と誤認させない | 9・10 | 名前や説明に「公式」「公認」を使わない |
| 生成AIを使った作品は「AI利用」と明記する | 6 | 制作に Claude を使うので、README に「AI利用」と書く |
| ゲームのデータを抽出して再配布しない | 7 | ゲームのファイルは解析しない |
| 重大なネタバレを避けにくい場所に書かない | 1 | README、サンプル、エラー文に犯人や結末を書かない |
| 特定の思想の主張や中傷に使わない | 3 | 該当する内容を含めない |
| 発信には用途別のハッシュタグを使う | 4 | 告知には `#まのさば二次創作` を使う |

## そのほかの法的な対応

- **コードのライセンス**: `MIT OR Apache-2.0` のデュアルライセンスにする。Rust と同じで、使う側がどちらかを選べる。許諾するのはこのリポジトリのコードだけで、作品の権利は含まないと README に書く。
- **Go のライセンス**: 実行ファイルと `wasm_exec.js` には Go のコード (BSD 3条項ライセンス) が含まれる。その著作権表示を `THIRD_PARTY_LICENSES` に入れて同梱する。
- **依存ライブラリ**: 自前で書くより保守しやすいなら、Go のライブラリ (標準・外部とも) を使う。実行ファイルに入るもののライセンスは、ビルドのときに go-licenses で集めて同じ `THIRD_PARTY_LICENSES` に入れる。

## 同梱の README (README.md) に書くこと

ガイドラインが日本語なので、文書はすべて日本語で書きます。リポジトリと配布物は同じ `README.md` を使い、仕様書 (`spec/`) も含めて英語版は作りません。

1. 「魔法少女ノ魔女裁判」の非公式のファンメイド作品であること。Acacia および合同会社Re,AER とは関係がなく、公認・監修を受けていないこと
2. 作品の権利は権利者にあること
3. 完全無料で、収益を得ていないこと
4. 「AI利用」 (生成AIを使って制作したこと)
5. 準拠したガイドラインのURLと最終更新日
6. キーワードに使った語の出典 (この仕様書の出典と同じもの)
7. ライセンスと、同梱した他者のライセンスの場所
8. この作品への問い合わせ先 (公式の窓口ではないことを添える)

キーワードに作品の単語を使うことが「公式素材の組み込み」に当たるかは、ガイドラインには書かれていません。公式は個別の事前確認には原則応じないため、文章ではなく単語だけを使うという範囲にとどめます。この章は法律の助言ではありません。
