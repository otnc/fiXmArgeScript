# マクロ

マクロは `curoi` (`cUrOi`、呪い) で定義します。マクロは実行の前にプログラムを書き換えます。最初の版では、受け取ったコードを型に当てはめるだけの方式にします (Rust の `macro_rules!` を簡単にしたもの)。

```
curoi twice(body)
  body
  body
finend

twice("Mof" redogh)  # Mof を2回出力する
```

- マクロの引数には、値ではなくコードが渡ります。展開は実行の前に1度だけです。
- 展開は字句の段階で、構文解析の前に行います。そのため引数には式だけでなく、`"Mof" redogh` のような文も渡せます。
- 引数が `1 + 2` のように2語以上の式なら、括弧で包んでから当てはめます。`square(1 + 2)` が `1 + 2 * 1 + 2` になることはありません。文を渡したときは包みません。
- マクロの中で作った変数は、展開のたびに別の名前に付け替えるので、呼び出し側の変数とぶつかりません (衛生的マクロ)。付け替えるのは、`izu` の左、`aste` の後ろ、`youlugive` の後ろに書いた名前です。
- マクロからマクロを呼べるのは、展開の深さ64段までです。超えると `Bavellabion` (あふれる) エラーです。1つのファイルの展開で字句が100万個を超えたときも同じです。
- マクロはファイルのどこで定義しても、そのファイル全体で使えます (`weho` の巻き上げと同じ)。同じ名前のマクロを2つ定義すると `Su·Ready` エラーです。ほかのファイルからは使えません (`oqun` は付けられません)。
- 呼び出しの引数の数が合わないと `AyAmis` エラーです。`util no twice(...)` のようにモジュールの中の名前として書いたものは、マクロとして扱いません。
- 最初の版では、マクロの本体の文字列にある `#{}` の中の引数の名前は置き換えません。`#{}` の中でマクロを呼ぶことはできます。
- 清書 (`.fxmac`) には展開する前の形が残ります。展開した結果は `fixmarge beaukshi --curoi` で確かめられます。
- 構文木を組み立てる本格的なマクロ (Lisp や Rust の手続き型マクロ) は、後の版で検討します。
