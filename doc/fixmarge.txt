1. 概要							*fixmarge* *fixmarge-intro*

fiXmArge Script (fxma) の下書き (`.fxma`) と清書 (`.fxmac`) を編集するためのプラグインです。「魔法少女ノ魔女裁判」の非公式のファンメイド作品で、公認・監修は受けていません。完全無料です。AI利用：生成AIを使って制作しています。

このプラグインがすること:

- ファイルタイプ `fixmarge` (下書き) と `fixmargec` (清書) を付ける。パッケージのファイル `fixmarge.mod` には `fixmargemod` を付けて項目名と文字列に色を付け、ロックファイル `fixmarge.sum` には `fixmargesum` を付ける (Vim は `*.mod` と `*.sum` を別の言語と見なすので、この2つは上書きする)
- 色分け。語の表から作っているので、`fixmarge` を入れていなくても色は付く
- インデント。下書きは `fixmarge beaukshi` と同じく空白2つで、ブロックの語 (`finend` など) を打ち終えるとインデントし直す。清書は `fixmarge sinruits` と同じくインデントしない
- コメント (`#`) の設定と、`gf` で `werer` の読み込み先を開くための 'suffixesadd'
- 言語サーバー `fixmarge trench` に自動でつなぐ。診断、補完、ホバー、定義へ移動、整形は言語サーバーが行う。|fixmarge-lsp| を見てください

対応するのは Vim 8.2 以降と Neovim 0.10 以降です。

2. 入れ方						*fixmarge-install*

このリポジトリがそのままプラグインです。どのプラグインマネージャーでも、リポジトリの名前を書くだけで入ります。言語サーバーを使うには、別に `fixmarge` を入れておきます (https://fixmargescript.oto.im/docs/start/install/)。

lazy.nvim (Neovim): >lua
	{ 'otnc/fiXmArgeScript' }
<
|vim.pack| (Neovim 0.12 から): >lua
	vim.pack.add({ 'https://github.com/otnc/fiXmArgeScript' })
<
mini.deps (Neovim): >lua
	MiniDeps.add('otnc/fiXmArgeScript')
<
packer.nvim (Neovim): >lua
	use('otnc/fiXmArgeScript')
<
paq-nvim (Neovim): >lua
	'otnc/fiXmArgeScript',
<
vim-plug (Vim・Neovim): >vim
	Plug 'otnc/fiXmArgeScript'
<
dein.vim (Vim・Neovim): >vim
	call dein#add('otnc/fiXmArgeScript')
<
vim-jetpack (Vim・Neovim): >vim
	Jetpack 'otnc/fiXmArgeScript'
<
Vim・Neovim のパッケージ (|packages|): >sh
	# Vim
	git clone https://github.com/otnc/fiXmArgeScript \
	  ~/.vim/pack/fixmarge/start/fiXmArgeScript
	# Neovim
	git clone https://github.com/otnc/fiXmArgeScript \
	  ~/.local/share/nvim/site/pack/fixmarge/start/fiXmArgeScript
<
パッケージで入れたときは、`:helptags ALL` でこのヘルプを引けるようにします。

版は `fixmarge` と同じ Git のタグ (`v0.1.0` など) で選べます。lazy.nvim なら `version`、|vim.pack| なら `version`、vim-plug なら `tag` に書きます。

3. 言語サーバー						*fixmarge-lsp*

`fixmarge` のファイルを開くと、言語サーバー `fixmarge trench` に自動でつなぎます。止めるときは |g:fixmarge_lsp| を 0 にします。

`fixmarge` は |g:fixmarge_path| の名前で `PATH` から探し、見つからなければインストール先も探します。`fixmarge` を入れる前から開いていた Vim は古い `PATH` のままなので、そのためです。

- Windows のセットアップ: `%LOCALAPPDATA%\Programs\fixmarge` (全員向けなら `%ProgramFiles%\fixmarge`)
- install.sh: `~/.fixmarge/bin` (`$FIXMARGE_INSTALL` があればその下の `bin`)
- `go install`: `$GOBIN` か `~/go/bin` (`$GOPATH` があればその下の `bin`)

どこにもなければ、つながずに `Nii eXi' fixmarge` と1度だけ出します。

Neovim ~
							*fixmarge-neovim*
Neovim 0.11 からは、このプラグインが |vim.lsp.config()| で `fixmarge` の設定を書き、|vim.lsp.enable()| でつなぎます。設定を変えるときは、このプラグインが読み込まれる前に |vim.lsp.config()| で書きます。先に書いた所はそのまま使い、書いていない所だけをこのプラグインが埋めます。 >lua
	vim.lsp.config('fixmarge', { settings = {} })
<
Neovim 0.10 は、ファイルを開いたときに |vim.lsp.start()| でつなぎます。

整形は |vim.lsp.buf.format()| です。

Vim ~
							*fixmarge-vim-lsp*
Vim には言語サーバーをつなぐ機能が組み込まれていないので、入っている LSP のプラグインに登録します。次の順に探し、最初に見つかった1つだけに登録します (2つに登録すると、同じ診断が二重に出るため)。

1. yegappan/lsp
2. vim-lsp (prabirshrestha/vim-lsp)
3. coc.nvim
4. ALE

どれも入っていなければ、色分けとインデントだけが使えます。

4. 設定							*fixmarge-options*

設定は、このプラグインが読み込まれる前に書きます (lazy.nvim なら `init`)。

							*g:fixmarge_lsp*
g:fixmarge_lsp			(既定 1)
	0 なら、言語サーバーに自動でつなぎません。自分の設定でつなぐときに使います。 >vim
	let g:fixmarge_lsp = 0
<
							*g:fixmarge_path*
g:fixmarge_path			(既定 'fixmarge')
	言語サーバーとして動かす `fixmarge` の名前か場所。名前だけなら `PATH` とインストール先から探し、パスを書けばそのファイルだけを使います。 >vim
	let g:fixmarge_path = '~/bin/fixmarge'
<
						*g:fixmarge_recommended_style*
g:fixmarge_recommended_style	(既定 1)
	1 なら 'expandtab' を付け、'shiftwidth' と 'softtabstop' を 2 にします (`fixmarge beaukshi` と同じインデント)。自分の設定を使うときは 0 にします。 >vim
	let g:fixmarge_recommended_style = 0
<
